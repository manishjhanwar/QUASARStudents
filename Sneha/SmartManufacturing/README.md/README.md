# ForgeOS — Smart Manufacturing Dashboard

A responsive, self-contained smart factory dashboard concept by **Sneha**.

## Run

Open `index.html` in any modern browser. No build step or package installation is required.

## Features

- At-a-glance OEE, output, machine availability, and energy metrics.
- Weekly production chart and first-pass quality breakdown.
- Shop-floor machine table with status, OEE, and output progress.
- Responsive sidebar and layouts for smaller screens.
- Lightweight interactions for navigation, time period, and machine list controls.

The values shown are sample dashboard data for demonstration.
