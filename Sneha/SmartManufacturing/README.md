# ForgeOS - Smart Manufacturing Dashboard

A responsive smart factory dashboard by Sneha.

## Run

Open `index.html` in a modern browser. No build step or package installation is needed.

## Features

- At-a-glance OEE, units produced, machine availability, and energy metrics.
- Weekly production chart and first-pass quality breakdown.
- Shop-floor machine table with status, OEE, and output.
- Responsive layout for desktop and mobile screens.
- Interactive date and machine-list controls.

All displayed metrics are sample data for demonstration.
